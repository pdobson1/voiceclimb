# Rungs — a voice-controlled word ladder

Play it: https://pdobson1.github.io/voiceclimb/

Fill in five words from their clues, put them in order so each word changes exactly one letter from the next, then solve the locked top and bottom words.

Everything can be done by voice (Chrome, Edge or Safari, with microphone access):

- Answer: "cord", "row 2 is word", "spell c o r d"
- Choose a rung: "row 3", "top", "bottom", "next"
- Reorder: "swap 1 and 4", "move 2 up", "move 5 to 1"
- Help: "clue", "read all", "hint", "give up", "check"
- Other: "clear", "new puzzle", "restart", "mute", "stop listening"

There's also a text box for the same commands, and you can type letters straight onto a rung.

On Mac, iPhone and iPad, Safari's speech recognition needs Dictation turned on.
